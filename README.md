### ویژگی‌ها
- ساخت پروفایل با **UUID یکتا**
- پشتیبانی از همراه اول، ایرانسل، رایتل، آپتل، سامانتل و شاتل
- رابط کاربری ساده و سریع
- کاملاً رایگان و متن‌باز

---

### نصب سریع
1. ریست شبکه انجام دهید
2. از [سایت](https://6itoon.github.io/6itoon-antenna/) پروفایل بسازید
3. فایل را نصب کنید
4. Data Roaming و VoLTE را روشن کنید
5. حالت هواپیما را یک‌بار روشن و خاموش کنید

> قبل از نصب پروفایل جدید، پروفایل قبلی را حذف کنید.
