# نتایج تست نسخه‌ها

هر نسخه فقط **یک** متغیر را نسبت به A عوض می‌کند، تا بشود فهمید دقیقاً کدام تغییر جواب داده.

| نسخه | احراز هویت | پروتکل | XLAT464 |
|---|---|---|---|
| A (پیشنهادی) | PAP + CHAP | IPv4 + IPv6 | روشن |
| B | فقط PAP | IPv4 + IPv6 | روشن |
| C | PAP + CHAP | فقط IPv4 | خاموش |
| D | PAP + CHAP | IPv4 + IPv6 | خاموش |

## روش تست (برای نتیجه قابل‌مقایسه)

1. **Reset Network Settings**
2. پروفایل قبلی شیطون انتن را حذف کنید
3. فقط **یک** نسخه را نصب کنید (نصب هر پروفایل شیطون انتن دیگر، قبلی را جایگزین می‌کند)
4. Data Roaming و VoLTE را روشن کنید و Airplane Mode را یک‌بار بزنید
5. گوشی را ریستارت کنید و ۱۰ دقیقه بعد وضعیت را ببینید
6. نتیجه را از [این فرم](https://github.com/6itoon/6itoon-antenna/issues/new?template=test-report.yml) گزارش کنید
7. اگر نسخه جواب نداد، به مرحله ۱ برگردید و نسخه بعدی را امتحان کنید

> بدون ریست شبکه بین هر تست، نتیجه قابل اعتماد نیست.
